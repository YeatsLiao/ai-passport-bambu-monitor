# 第四批：配网、配对与连接恢复

本批实现之前确认的第 1、2、3、6 项。设备自动发现、异步配网任务和手机重连后查询进度留待下一批。

## 已实现

- 配对成功要求登录 MQTT、订阅指定序列号的 report、发送 pushall，并收到包含有效字段的完整报文。错误主题、保留报文、空对象、无关字段、乱序分片和超限报文不能作为成功凭据。支持超过 23 KB 的分片报文；候选配置验证不会写入监控状态。
- 表单以当前配置为基础合并，保留亮度、熄屏时间及未提交的显示偏好。仅修改打印机时保留 WiFi；仅修改 WiFi 时保留打印机。更换 SSID 必须重新填密码，更换序列号必须重新填访问码；同一对象的密码留空才沿用旧值。
- 严格校验字段字节长度、URL 编码、重复字段、IP、序列号及 8 位访问码。HTTP 请求体分段读取，避免只处理第一段。32 字节 SSID 不再截成 31 字节。
- 新配置先保存为 trial，保留 stable 网络配置。开机后 90 秒内收到指定 report 的有效数据，才确认并保存显示偏好；失败则删除 trial、恢复旧配置并重启。首次配置失败则回到未配置入口。强制跳过验证的配置也必须通过这次试运行。
- 配网界面长按 OK 可取消，停止验证、HTTP、DNS 和 AP，恢复原监控连接。保存已进入重启阶段时不再接受取消。配网期间暂停自动熄屏。
- 所有网络启动与停止由主任务执行，按键只发送请求。WiFi 延迟拿到 IP 后仍会启动 MQTT；客户端创建或启动失败每 2 秒重试，已创建客户端使用 MQTT 库重连。主动停止不会触发 WiFi 重连；重复初始化默认事件循环不会中断恢复。
- 配网页区分验证通过与跳过验证，提示试运行与回退。取消页面后恢复监控页，提示文字覆盖中英文。

## 验证

- `tools/test_reports.py`：真实报告解析器及 pairing probe；错误主题、保留消息、空/非法数据、乱序、23 KB 分片、96 KB 上限、验证不污染监控状态；原有 AMS/HT/外挂盘用例继续通过。
- `tools/test_display_config.py`：真实显示设置保存失败与范围校验。
- `tools/test_provisioning.py`：真实表单与配置代码；独立修改、密钥沿用边界、32 字节 SSID、异常编码、trial 重启/确认/回退、显示偏好保留；对暂存和确认各存储操作注入失败，验证重启后仍可恢复或重试。
- `tools/test_mqtt_lifecycle.py`：真实 MQTT 管理代码配 ESP 事件/时钟桩；延迟 DHCP、分配失败、启动失败、重复启动、错误主题、保留报文、主动停止及再次启动。
- 实际 LVGL 模拟器：12 风格 × 中英文通过；新增配网页显示和取消恢复，所有提示在屏幕内。调整中文短提示后复查 Pixel、Apple 中英文。
- 中文字体覆盖检查通过，无缺字；配网页 JavaScript 通过 Node 语法检查；`git diff --check` 通过。
- ESP-IDF 5.5.5 固件编译通过，应用大小 `0x1b3650`，3 MB 应用分区剩余约 43%。产物为 `build/ai-passport-bambu-monitor.bin`。

## 仍需实机验收

本批未烧录，测试桩不代表真实断电、射频或打印机固件测试。需要在 ESP32-C3 上验证：错误密码/访问码/序列号、验证中长按 OK、手机热点切换信道、路由器晚启动、保存后断电以及旧配置恢复；同时观察 TLS 握手和大报文接收时的剩余堆。

配网验证仍在 HTTP 请求内同步执行，手机掉线后的任务查询/恢复、自动发现打印机和分阶段进度属于下一批。当前主要通过设备长按 OK 取消。未增加 BLE 配网或云账号绑定。
