# 第三批：设置页与交互 · 2026-11-03

完成原排查方案中设置页主题一致性、长文案、状态反馈、取消与保存的代码实现。设置页使用一套业务逻辑，由主题样式参数控制呈现。

## 界面

- 复用原主题的顶栏、时钟、电池和底栏；仅切换内容区，设置期间继续更新时钟和电池。
- 12 套主题各有设置样式参数：框线、圆角、分隔线、编号、读数条等。像素保留直角、纸牌和硬投影；SSD 延续金色分隔；工业主题使用方形编号行；F1 保留红色包边和计时行；Geist 使用平面与发丝线；Apple 延续浅色分组卡片。
- 选中态和编辑态使用固定尺寸的底色、游标、符号和文案反馈；边框宽度不随选中改变。
- 名称和值使用独立固定列宽，编辑箭头不再挤入值列。配网二次确认显示在独立提示行，不挤占行名。
- 底栏按浏览、编辑、确认显示不同操作提示；右侧显示当前设置项序号，返回后恢复实际监控页码。
- 正文与数值颜色根据实际背景检查对比度，优先保持主题文字颜色，必要时回落到黑/白；亮色强调主要用于底色、游标和分隔线。

## 交互与文案

- 上下键浏览；OK 进入编辑；编辑时上增下减，OK 保存，长按 OK 取消。亮度在 10–100% 内调节，不在边界突然循环。
- 取消亮度编辑立即恢复已保存的亮度，不必退出整个设置页。
- 保存成功后显示“已保存”。失败保留编辑值和预览，显示“保存失败，OK 重试”；用户可以重试或长按取消。
- 配置 setter 先尝试持久化，再更新运行时配置；NVS 失败不会让运行中的设置误变为新值。
- 熄屏支持关闭、1/3/5/10/30/60 分钟；对已保存的非预设值（如 7 分钟）原样显示，直接确认不会悄悄变成 5 分钟。
- 配网仍需连续两次 OK；移动选择或长按 OK 会撤销确认，回调只在再次确认后执行。
- “重置网络”改为“重新配网”（英文简写为 Network），更准确表达进入配网页的动作；相关操作提示统一进入双语表。
- 主题与语言选择继续使用现有配网页。这一批完成设备设置页的视觉与操作；设备端即时换主题属于原方案中的可选扩展。
