UI 设计 Token 预览 · 12 套风格

每套忠实于自身主题（Pixel 硬边、Cyber 霓虹、F1 计时塔…），此处展示的是各套的语义色槽位与文字/进度示例， 并实时计算 WCAG 对比度。开启校验后，任何低于正文 4.5:1 / 大字与图形 3:1 的配色都会标红。带 * 的套里，某些明亮色按主题设计 只作带墨黑描边/托底的色块（如 Pixel 围巾橙、亮黄），不参与纸牌文字对比校验。色值与 main/ui/ui_theme.c 保持一致。

正文需 ≥ 4.5:1，大字/进度/色块需 ≥ 3:1（AA）

说明：本文件是离线设计对照工具，不参与固件编译。真机各风格的独特版式（仪表环 / SSD 标签 / F1 行卡等）由对应 style_*.c 实现，这里统一用同一套示例布局仅为了横向核对配色与可读性。
